🧠 Objetivo
Desenvolver um site institucional para a escola fictícia EduTech Academy, utilizando múltiplas páginas HTML, layout responsivo com CSS, modo claro/escuro e interações em JavaScript como validação de formulário e preenchimento automático de endereço via API ViaCEP.

🧱 O que você deve desenvolver

Você criará um site completo com múltiplas páginas, utilizando:
HTML semântico
CSS moderno com responsividade (Flexbox ou Grid)
Variáveis CSS e Google Fonts (Poppins e Inter)
JavaScript puro para interatividade
API pública ViaCEP para buscar endereços

🔗 Páginas obrigatórias: 
1. index.html – Página Inicial
Título de boas-vindas
Cards com 4 cursos (imagem, título, carga horária, modalidade, botão "Ver mais")
Cabeçalho com logo e menu
Botão de alternância de tema claro/escuro
Rodapé com redes sociais fictícias

2. cursos.html – Lista de Cursos
Repetição dos cursos com links para páginas individuais

3. 4 páginas de cursos:
curso-web.html
curso-datascience.html
curso-marketing.html
curso-uxui.html
Com informações completas do curso, conteúdo programático e chamada para ação

Funcionalidades exigidas:
✅ Validação de campos obrigatórios com mensagens de erro usando o Javascript e com as mensagens de erros conforme documento em anexo.
✅ Preenchimento automático de endereço usando a API do ViaCEP
✅ Modo claro/ escuro

🌐 Uso de Internet
✅ Permitido:
✅ Acesso ao W3Schools
✅ Consulta ao material de apoio no Notion (Disponibilizado no Classroom)
✅ Acesso à documentação oficial da API ViaCEP
✅ Uso do Google Fonts apenas para importar Poppins e Inter

🧪 Critérios 
✅ HTML semântico, organização das páginas
🎨 CSS moderno com responsividade e variáveis
🅰️ Uso de fontes Poppins e Inter do Google Fonts
🌗 Modo claro/escuro funcional com persistência (localStorage)
📄 Conteúdo dos cursos fiel às instruções
📋 Formulário de matrícula com validação em JS
🌐 Consumo correto da API ViaCEP
🧩 Organização de arquivos, boas práticas e clareza do código
